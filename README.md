# 英语单词双法记忆 · Dual-Method English Word Memory

一个技能包（Agent Skill）：对每个英语单词**同时给出两版独立记忆方案**，并列展示、对比择优。当前版本 **v1.2.0**。

- **方法一 · 联想记忆法** — 把单词拆成熟悉碎片，用熟词 / 拼音 / 编码 / 谐音映射到中文画面，焊成一句越荒诞越通感越好记的串联句。
- **方法二 · 词根词缀记忆法** — 拆「前缀 + 词根 + 后缀」，由词素义推导词义。

两版各自闭环，**同一版内不混写**：联想版不掺词素推导，词素版不掺荒诞画面。某法不适用时标注「不适用」并说明原因。

> An agent skill that produces **two independent mnemonic plans** for each English word — an associative one (familiar words, pinyin, letter codes, homophones woven into a vivid sentence) and a morphological one (prefix + root + suffix) — shown side by side for comparison.

## 安装

克隆到 skills 目录即可（仓库根即 skill 包）：

```bash
git clone https://github.com/wzseanbiz-netizen/english-word-memory-skill.git \
  ~/.workbuddy/skills/english-word-memory
```

也可复制到任意支持 `SKILL.md` 的 Agent 技能目录（Claude Code、Cursor、Codex 等）。

无第三方依赖。`scripts/word_memory.py` 仅用 Python 3 标准库。

## 用法

触发即可，无需命令：

- 帮我记一下 `transportation` 这个单词
- 用两种方法给我记 `suppose`、`birthmark`、`bright`
- 给 `accommodation` 编个记忆法（可注明学段：小学 / 初中 / 高中 / 成人）
- 批量：一行一个单词，或 `word | 释义 | 词性`

输出结构：

```text
【word】释义（词性）

▍方法一 · 联想记忆法
切分：…（1–4 段灵活，整词单段也合法，按原字母顺序）
译码：…（每段标注 熟词/拼音/编码/谐音）
碎片意象：…（每段一个荒诞镜头）
串联成句：…（一句，词义融进画面）
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
拆词素：前缀 + 词根 + 后缀
解义 / 组义 / 锚定
复习：当天 / 隔天 / 每周

▍择优建议：该词更适合哪版、为什么
```

### 机械辅助（可选）

脚本不编含义，只做机械匹配，创意仍由 Agent 完成：

```bash
python3 scripts/word_memory.py transportation            # 联想法：切分候选 + 译码建议 + 双写段候选
python3 scripts/word_memory.py transport --mode affix    # 词根词缀：自动匹配前后缀
```

## 规则体系（v1.2.0）

本版把实测踩坑换来的经验固化为一套可执行规则（详见 `docs/` 三份验证文档）：

1. **段数由词决定** — 1–4 段灵活：能整词就整词（整词熟词单段合法），能 2 段不 3 段，上限 4 段。总判据：这套拆法背起来要比直接背单词省力。
2. **四法优先级 + 谐音三关** — 熟词 > 拼音 > 编码 > 谐音，前三法有干净解绝不用谐音；谐音必须过三关（读音真接近 / 意象真实存在 / 画面与词义因果连接），过不了宁可不改别硬凑。合法例外：整词音译词（coffee→咖啡）天然三关全过。
3. **单句因果链（最高优先级·一票否决）** — 一条串联句只能是一条因果链，禁止画面并列；词义必须人物手上正干的活儿，禁「是个X / 成了X / ——这就是X」贴标收尾。
4. **拼接核对（机械动作）** — 切分定稿前把各段字母按序拼回、逐字符等于原词（bu+tt+er+fly→"butterfly" ✓；bu+te+r→只有"butter" ✗ 当场现形）。声明式规则防不住注意力漂移，核对必须是"不做就没法定稿"的动作。
5. **学段适配（熟词分级）** — 熟词以学习者学段为准：小学只收课本级词汇（apple/cat/run 级），超学段片段用象形编码 + 拼音首字母补位（零英语词汇量门槛）。
6. **拼音准确性** — 拼音段汉字读音必须与字母严格对应（ca→擦 cā 对，写成"卡 kǎ"就是错），不许抓音近字充数。
7. **双写字母段选型** — 要"动"（追/喊/抱）用拼音首字母人物词（pp→婆婆，表见 `mapping.json` `pinyin` 段）；当道具用编码复数（ss→两条海马、tt→两把伞）；画面质量相当时优先编码复数（与单字母表一致、零新增）。`pinyin` 表按全库 8105 真词分布修剪：ii/jj/kk/qq/vv/ww/xx/yy 零出现，一律不收。
8. **熟词真义铁律** — 标「熟词」必须是该英文片段字典里的真实常用义，对不上改标「编码」。

## 几条硬约束（节选自 SKILL.md）

1. **模块顺序锁定** — 拆分模块按单词原字母顺序出现，不得跳序。
2. **词义融合** — 中文词义要成为画面里活着的角色，不能句尾甩标签「——这就是 X」。
3. **中文句法通顺** — 主谓宾正常，硬插注释、语序颠倒、拗口一律筛掉重写。
4. **字母全覆盖** — 每段译码覆盖该段全部字母，定稿前过拼接核对。
5. **单句因果链** — 只能一条因果链，画面并列即废。
6. **只编一句** — 越长越稀释情绪。荒诞 → 通感 → 刺激 → 威胁感，强度逐级叠加。

## 适用与不适用

- **小学**（词短具象）：以方法一为主，拼音首字母 + 象形编码，1–2 个片段，句子生活化；熟词只限课本级词汇。
- **初中**（词长抽象）：派生词用方法二独立推导；词形不透明的回方法一。
- **同族词**：方法二优先，按词根 / 前后缀成组效率最高。
- **不适用**：不负责发音教学、语法讲解、整句翻译；不为单词编造与发音 / 拼写无关的联想。
