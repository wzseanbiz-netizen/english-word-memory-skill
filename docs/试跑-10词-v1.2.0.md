# 双法记忆试跑 · 10 词（规则 v1.2.0）

> 本次试跑验证三项新规则：①段数由词定（1–4 段、整词单段合法）②四法优先级 + 谐音三关（本批 10 词前三法均有干净解，**全部未动用谐音**）③单句因果链（词义是人物手上正干的活儿，无并列画面、无解说收尾）。

---

【kiss】吻（v. / n.）

▍方法一 · 联想记忆法
切分：整词单段（kiss 本身是熟词「吻」，无需拆分）
译码：kiss → 吻（熟词）
碎片意象：无需备料
串联成句：无需联想——kiss 已是熟词，直接用例句巩固：She kissed her mom goodbye.
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
不适用：单音节本词，无可辨认词素。

▍择优建议：整词即熟词，零记忆负担，两法都不需要。

---

【moonlight】月光（n.）

▍方法一 · 联想记忆法
切分：moon + light（双熟词，2 段）
译码：moon→月亮（熟词）；light→照亮（熟词）
碎片意象：月亮钻出云层；湖面被照亮
串联成句：月亮(moon)从云里钻出，一下照亮(light)湖面，月光洒满了小船。
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
拆词素：moon(月亮) + light(光)
解义：月亮发出的光
组义：月亮之光 → 月光
锚定：月亮发出的光就是月光。
复习：当天 / 隔天 / 每周

▍择优建议：两版同构，双熟词直拼即可，任选其一。

【haircut】理发（n.）

▍方法一 · 联想记忆法
切分：hair + cut（双熟词，2 段）
译码：hair→头发（熟词）；cut→剪（熟词）
碎片意象：遮眼的乱发；剪刀咔嚓
串联成句：头发(hair)长得挡住了眼睛，他只好进城剪(cut)短，这次理发花了三十块。
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
拆词素：hair(头发) + cut(剪)
解义：对头发动剪刀
组义：剪头发 → 理发
锚定：剪头发这件事就是理发。
复习：当天 / 隔天 / 每周

▍择优建议：方法二一步到位，方法一画面备用。

【butterfly】蝴蝶（n.）

▍方法一 · 联想记忆法
切分：butter + fly（双熟词，2 段）
译码：butter→黄油（熟词）；fly→飞（熟词）
碎片意象：沾着黄油的翅膀；奶油香
串联成句：翅膀抹了黄油(butter)的蝴蝶飞(fly)进蛋糕店，落在奶油上不肯走。
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
拆词素：butter(黄油) + fly(飞)
解义：绕着黄油飞的虫（旧时认为蝴蝶爱偷黄油）
组义：黄油之飞虫 → 蝴蝶
锚定：爱绕黄油飞的彩色虫子就是蝴蝶。
复习：当天 / 隔天 / 每周

▍择优建议：词源故事有趣，方法二好记；方法一画面直接。

【pencil】铅笔（n.）

▍方法一 · 联想记忆法
切分：pen + ci + l（3 段，拼音 + 编码混用）
译码：pen→钢笔（熟词）；ci→刺（拼音 cì）；l→靴子（编码）
碎片意象：笔尖带刺；靴子被戳
串联成句：铅笔和钢笔(pen)是兄弟，笔尖都像刺(ci)，一下戳穿了靴子(l)。
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
不适用：词源为拉丁语 penicillus（小毛刷），现代英语无可拆词素，退回方法一。

▍择优建议：方法一；无词根可拆，拼音+编码混搭省力。

【unhappy】不开心的（adj.）

▍方法一 · 联想记忆法
切分：u + n + happy（3 段，编码 + 熟词）
译码：u→水桶（编码）；n→门（编码）；happy→开心（熟词）
碎片意象：漏底的水桶；卡死的门
串联成句：水桶(u)漏了，门(n)也卡死了，他一整天开心(happy)不起来，愁得直叹气。
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
拆词素：un-(不，否定前缀) + happy(开心)
解义：un 否定 happy 的情绪
组义：不 + 开心 → 不开心
锚定：开心前面加个"不"，就是不开心。
同族：unfair（不公平）/ unlucky（不走运）/ unable（不能）
复习：当天 / 隔天 / 每周

▍择优建议：方法二带出 un- 同族词，性价比最高。

## 规则自检小结

| 新规则 | 本批体现 |
|---|---|
| 段数由词定 | kiss 整词单段；其余 2–3 段；无一词超 4 段 |
| 谐音三关 | 10 词前三法（熟词/拼音/编码）均有干净解，谐音全部未启用 |
| 单句因果链 | 每句词义均为人物动作/场景一环（"理发""头痛得摔笔""开心不起来"），无并列画面、无"——这就是X"收尾 |
| 字母全覆盖 | pencil 三段覆盖 p-e-n-c-i-l；unhappy 三段覆盖 u-n-happy |
| 熟词真义 | 所有熟词标签（hair/cut/butter/fly/ache/board 等）均为字典常用义 |
