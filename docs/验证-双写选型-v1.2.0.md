# 双写选型 + 谐音三关验证跑 · 5 词（规则 v1.2.0）

> 验证目标：①双写段"人物词 vs 编码复数"选型判据 ②谐音三关何时能过（音译词正面示例）③方法一/方法二双适用词的处理。学段未指定，逐词推断标注。

---

【letter】信件（n.）· 初中

▍方法一 · 联想记忆法
切分：le + tt + er（3 段）
译码：le→乐（拼音 lè）；tt→太太（拼音首字母·人物）；er→耳朵（拼音 ěr）
碎片意象：笑得合不拢嘴；信纸贴耳
**双写选型**：tt 位是"收信的当事人"，句中要有情绪动作 → 选人物词「太太」而非"两把伞"。
串联成句：乐(le)坏了的太太(tt)，把新信件贴在耳朵(er)边反复读。
**拼接核对**：le+tt+er → "letter" ✓
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
不适用：无可辨认词素。

▍择优建议：方法一。

【hurry】匆忙（v. / n.）· 初中

▍方法一 · 联想记忆法
切分：hu + rr + y（3 段）
译码：hu→湖（拼音 hú）；rr→两棵小草（编码复数）；y→晒衣杆（编码）
碎片意象：湖水漫草；抢收晒衣杆
**双写选型**：rr 位是场景道具（被水漫过的草），无动作需求 → 选编码复数"两棵小草"，与单字母表 r=小草 一致，零新增。
串联成句：湖水(hu)漫过两棵小草(rr)，他抓起晒衣杆(y)匆匆忙忙往家赶。
**拼接核对**：hu+rr+y → "hurry" ✓
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
不适用：无可辨认词素。

▍择优建议：方法一。

【daddy】爸爸（n.）· 小学低年级

▍方法一 · 联想记忆法
切分：da + dd + y（3 段）
译码：da→大（拼音 dà）；dd→弟弟（拼音首字母·人物）；y→晒衣杆（编码）
碎片意象：小大人；举杆当话筒
**双写选型**：dd 位是句中的动作主体（举杆学说话）→ 选人物词「弟弟」。
串联成句：大(da)弟弟(dd)举着晒衣杆(y)当话筒，学爸爸说话逗全家笑。
**拼接核对**：da+dd+y → "daddy" ✓
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
不适用：无可辨认词素（口语叠词）。

▍择优建议：方法一。

【return】返回（v.）· 初中 ★双法皆适用

▍方法一 · 联想记忆法
切分：re + turn（2 段）
译码：re→热（拼音 rè）；turn→转身（熟词·初中）
碎片意象：满头大汗；掉头就走
串联成句：热(re)得直冒汗，他转身(turn)往家走，返回途中还买了根冰棍。
**拼接核对**：re+turn → "return" ✓
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
拆词素：re-(回，前缀) + turn(转)
解义：转回去
组义：回 + 转 → 返回
锚定：转回去就是返回。
同族：reuse（重复用）/ rebuild（重建）/ review（回看=复习）

▍择优建议：**方法二**——re-+turn 两步直解，还带出一串 re- 同族；方法一留作画面备用。

【coffee】咖啡（n.）· 小学高年级/初中 ★谐音三关正面示例

▍方法一 · 联想记忆法
切分：整词单段（谐音）
译码：coffee→咖啡（谐音·音译词）
**谐音三关逐条过**：①读音真接近——coffee 本身就是"咖啡"的音译源词，天然成立；②意象真实——一杯热咖啡，一眼出画面；③因果连接——咖啡入词义本身，无需外接。三关全过，谐音可用（此为四法优先级中"前三法无干净解才用谐音"的合法例外：整词音译，无需拆分）。
串联成句：加班到半夜，一杯热咖啡(coffee)下肚，困意全消。
**拼接核对**：整词，无拆分，天然通过 ✓
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
不适用：音译外来词，无英语词素。

▍择优建议：整词谐音即词义，零负担——音译词（coffee/sofa/salad 一族）是谐音法的天然合法区。

## 验证结论

| 检查项 | 结果 |
|---|---|
| 双写选型-人物 | ✓ letter(tt 太太收信)、daddy(dd 弟弟表演)——段位要"动"，选人物词 |
| 双写选型-道具 | ✓ hurry(rr 两棵小草被水漫)——段位是场景物，选编码复数，与 r=小草 一致 |
| 谐音三关正面用例 | ✓ coffee 音译词三关全过——谐音的合法区是"整词音译"，与"宁可不改别硬凑"不冲突 |
| 双法皆适用 | ✓ return 方法二 re-+turn 直解且带 re- 同族，择优给方法二、不删方法一 |
| 拼音准确性 | ✓ le乐/hu湖/da大/re热 读音均与字母严格对应 |
| 拼接核对 | 5 词全部通过；无双写字母漏挂 |
| 学段适配 | letter/hurry/return/coffee 初中级熟词可用；daddy 走拼音+人物词 |

**结论**：双写选型判据（要"动"用人物、当道具用编码复数）在 5 词中全部给出一致选择；谐音三关在音译词上给出了首个合法正面用例，规则体系的"禁"与"放"边界都跑通了。
