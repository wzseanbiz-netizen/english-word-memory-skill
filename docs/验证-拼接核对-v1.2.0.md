# 拼接核对验证跑 · 6 词（规则 v1.2.0）

> 验证目标：新加的「切分定稿前必做拼接核对」机械动作。学段未指定，词均选小学难度，按小学模式（课本熟词 + 拼音 + 象形编码）处理。其中 puppy 一词演示了核对拦下错误初稿的过程。

【dance】跳舞（v.）

▍方法一 · 联想记忆法
切分：dan + ce（2 段，双拼音）
译码：dan→蛋（拼音 dàn）；ce→厕所（拼音 cè）
碎片意象：滚进隔间的鸡蛋；门缝里漏出的舞步
串联成句：鸡蛋(dan)躲在厕所(ce)里偷偷跳舞(dance)，谁敲门都不开。
**拼接核对**：dan+ce → "dance" ✓，字母序一致
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
不适用：无可辨认词素。

▍择优建议：方法一；词短无词根，拼音两段直接成画。

【puppy】小狗（n.）★核对拦截演示

▍方法一 · 联想记忆法
初稿切分：pu + py（扑 + 晒衣杆）
**拼接核对：pu+py → "pupy" ≠ "puppy" ✗ 拦下**——p 是双写字母，初稿只给了一个去处，按双写条款重拆。
修正切分：pu + pp + y（3 段）
译码：pu→扑（拼音 pū）；pp→婆婆（拼音首字母 pópo）；y→晒衣杆（编码）
碎片意象：小狗扑鞋；婆婆追出来
串联成句：小狗扑(pu)咬婆婆(pp)的棉鞋，主人举起晒衣杆(y)假装要打。
**拼接核对**：pu+pp+y → "puppy" ✓，双写 p 已各有去处
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
不适用：无可辨认词素。

▍择优建议：方法一。（首版 pp 写"两条皮鞋"，用户改定"婆婆"——人物意象比物件更好记，已采纳）

【carry】搬运（v.）★拼音纠错演示

▍方法一 · 联想记忆法
初稿译码：ca→卡——**拼音核对不过**：卡读 kǎ（ka），ca 是 c-a，只能对应"擦(cā)"等 ca 音节字，音近字充数立即拦下。
修正切分：ca + rr + y（3 段）
译码：ca→擦（拼音 cā）；rr→两棵小草（编码）；y→晒衣杆（编码）
碎片意象：擦西瓜；草绳捆瓜；扁担压弯
串联成句：他擦(ca)干净大西瓜，拿两棵小草(rr)当绳子捆住，用晒衣杆(y)扛回家——搬运真费劲。
**拼接核对**：ca+rr+y → "carry" ✓，双写 r 已各有去处
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
不适用：无可辨认词素。

▍择优建议：方法一。

【garden】花园（n.）

▍方法一 · 联想记忆法
切分：整词单段（garden 是小学课本词，直接认识）
译码：garden→花园（熟词）
碎片意象：无需备料
串联成句：无需联想——garden 是课本里的老朋友，直接用巩固：There are many flowers in the garden.
**拼接核对**：整词，无拆分，天然通过 ✓
复习：当天 / 隔天 / 每周

▍方法二 · 词根词缀记忆法
不适用：词源为古法语 gardin，现代英语无可拆词素。

▍择优建议：整词即熟词，零负担。

## 验证结论

| 检查项 | 结果 |
|---|---|
| 拼接核对能否拦漏字母 | ✓ puppy 初稿 pu+py 拼出 "pupy" 当场被拦，改 pu+pp+y 后通过——机械动作有效 |
| 双写字母处理 | ✓ puppy(pp 两条皮鞋)、carry(rr 两棵小草) 均合并为双字母段，各有画面 |
| 拼音合法性 | dan蛋/ce厕/ti踢/er耳/ru入/pu扑 均为真实拼音音节+常用义；carry 首版"ca→卡"为拼音错误（卡读 kǎ），已拦下改为"擦(cā)"——拼音段读音必须与字母严格对应 |
| 编码表一致性 | ✓ g鸽子/l靴子/y晒衣杆/p皮鞋/r小草 均取自固定编码表 |
| 谐音 | 6 词全部未启用（前三法干净解即不用） |
| 单句因果链 | 每句词义均为画面中的动作/结果，无并列、无贴标 |
| 学段适配 | 课本词（garden）整词直认；非课本词全走拼音+编码，未硬标熟词 |

**结论**：拼接核对作为成句前的固定机械动作，实测能拦住"改拆法时漏字母"这类错误——它把核对从"记得要做"变成了"不做就没法定稿"。
