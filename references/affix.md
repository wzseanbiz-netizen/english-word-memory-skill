# 词根词缀记忆法（方法二 · 形态拆解法）

> **定位**：本 skill 的**第二种记忆法**，与「联想记忆法」并列、互补。同一单词下**两版方案并列呈现、方案内不混写**（不把词素推导与联想画面拼在同一记忆句里）。它靠"词素义推导"记词义与同族，适合派生词明显、初中长词、同族词、抽象学术词。
>
> **事实边界（诚实标注）**：本表来自**通用英语词源/形态学常识**，并非两份 PPT 原文（PPT 仅提及"熟词法+词根词缀"而未给出此表）。本表是**编纂性参考**，可随教学增删；词素含义为常见义，具体词中可能有引申。

---

## 一、何时优先用本法
- 单词有可辨认的前缀/后缀/词根（如 un-, re-, -tion, -able, port-, spect-）。
- 初中及以上长词、抽象词、学术词（transport、biology、international）。
- 同族词（inject / reject / object / project 共享 -ject"投掷"）。
- 反之，词形不透明、小学具象短词、需强情绪记忆的词，用联想记忆法更顺。

## 二、方法步骤（六步）
1. **定词**：写明 word、pos、meaning、example；缺省则补全并标注。
2. **拆词素**：拆成 `前缀 + 词根 + 后缀`。词根可来自拉丁/希腊词根或熟词；拆不出词根退回方法一。
3. **解义**：前缀表方向/否定/程度，词根表核心义，后缀表词性/类别；逐段标中文义。
4. **组义**：把词素义串成中文释义，与单词实际词义校准（transport = trans跨 + port运 → 运输）。
5. **锚定（可选）**：用一句平实话把词素义与词义绑住（"跨着运就是运输"）。**不引入联想法的荒诞画面**。
6. **固化 + 归纳**：间隔复习；同根词成组（如 -ject 家族）。

## 六、与方法一（联想记忆法）的关系：并列呈现、方案内不混写
- **同一词并列两版**：对每个单词同时产出方法一（联想）与方法二（词根词缀）两版独立方案，并列在同一单词下供对比择优。
- **方案内不混写**：词素版只用词素义平实串联，不引入荒诞场景；联想版不掺词素推导。两版各自独立闭环。
- **某法不适用时**：如无可辨词素，方法二栏标「不适用」，保留方法一版。
- **方法一内部的四法混用**决策（熟词/拼音/编码/谐音）仍只在方法一内部，与方法二无关。

## 七、练习示例
- **transport = 运输**：trans(跨)+port(运) → "跨着运就是运输"。
- **biology = 生物学**：bio(生命)+logy(学) → 生命之学。
- **unbelievable = 难以置信的**：un(不)+believe(相信)+able(能…的) → 不能相信的。
- **predict = 预测**：pre(前)+dict(说) → 事先说。
- **international = 国际的**：inter(之间)+nation(国家)+al(…的) → 国家之间的。
