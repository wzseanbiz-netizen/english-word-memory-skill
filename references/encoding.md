# 英文编码表（字母 / 字母组合 → 固定中文意象）

> **来源**：《英文编码.pptx》（共 140 页）。该 PPT 给出一套**固定**的"英文字母 / 字母组合 → 中文意象"编码，用于记单词拼写为先、兼顾含义。本表是 skill「编码法」的**权威映射源**：凡走编码法，优先查本表与 `scripts/mapping.json` 的 `encoding` 段，保证不同单词的同一字母/组合意象一致。
>
> **定位（重要）**：编码法只是方法一四法（熟词 / 拼音 / 编码 / 谐音）中的**之一、且非默认**。拆分时**优先用熟词法 / 拼音法把大块并成好记的中文**；只有当某段熟词、拼音都无好解时，才用本表编码。**不要为了用编码法而逐字母拆分**——逐字母模块多、意象散，反而比少模块拆法更难记。本表的价值在于"拼写的某一小段没更好办法时的兜底"，不是首选项。
>
> **事实边界（诚实标注）**：
> - Part 1「26 个单字母编码」、Part 2「字母组合编码表」为 PPT 明确内容（第 4–55 页、第 59/84/109/110 页表格）。
> - Part 3「编码法记忆英文单词」在 PPT 中仅以练习词表 + 检查/复习页呈现（第 56–57、125–139 页），其"如何把意象串成记忆句"的应用步骤为本文结合七步框架的归纳，**非 PPT 原文逐字**，已显式说明。
> - 本表覆盖常见字母与高频组合，非穷尽；未命中的单字母回落到下方 26 字母表。**注意**：仅当该段确实需要编码时才用；能并入熟词/拼音大模块的，不要拆到单字母。

## 三、如何用编码法记单词（与七步框架衔接）

编码法的定位：把单词的**拼写**逐段翻译成一组固定意象，再用七步框架第 4–5 步把这些意象荒诞/通感地焊成一句（词义须融进剧情，不能贴标签）。

1. **步骤 2 切分**：组合优先、单字母兜底，把单词切成编码单元。
   - 例：`moon` → `m` + `oo` + `n`；`yarn` → `y` + `ar` + `n`；`fox` → `f` + `o` + `x`。
2. **步骤 3 译码**：每个单元查本表得固定意象。
   - `moon` → 汉堡包 + 眼镜 + 门；`yarn` → 晒衣杆 + 矮人 + 门；`fox` → 斧头 + 甜甜圈 + 剪刀。
3. **步骤 4 碎片意象**：给每个意象造一个不合常理的镜头（只备料）。
4. **步骤 5 串联成句**：把意象 + 英文词义焊成一句，遵守成句硬约束（模块顺序锁定、词义融合、中文通顺、字母全覆盖、只编 1 句）。
   - `moon`：「把汉堡包(m)塞进眼镜(oo)，门(n)后藏着的正是月亮(moon)。」
   - `fox`：「斧头(f)劈开甜甜圈(o)，剪刀(x)扎向那只狐狸(fox)。」
5. **步骤 6/7**：间隔复习 + 同族归纳（如 `-tion` 家族统一用「神」作后缀意象）。

> 机械辅助：运行 `python3 scripts/word_memory.py 单词` 会输出「步骤 3b 编码意象候选」（组合优先、单字母兜底）。注意这些只是四法之一的候选，优先用熟词/拼音把大块并成好记中文，勿逐字母拆。
