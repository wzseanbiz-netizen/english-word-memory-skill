# 成句示例库（示范）

> 本文件提供可直接套用的成句**示范**，覆盖六类方法。智能体在生成新助记时，应优先达到示例的情绪强度与融合度。所有示例均含英文词义本身，且模块按原字母顺序排列。
>
> ⚠️ 诚实边界（事实与推测）：下列拆解与串联句，是**按本方法规则由人/模型创作的示范**，并非经过记忆召回实验验证的"最佳助记"。`scripts/mapping.json` 仅是**非穷尽的候选音映射库**（取自小学/初中词汇实例 harvest 片段），不要求逐字对应；脚本未命中某词属正常，创意拆解由智能体完成（见 `SKILL.md` 步骤 3、5）。示例用于标定"成句质量下限"，而非声称实测效果。

## 1. pilot = 飞行员（编码法 + 中插最融合）

```
【pilot】飞行员（n.）
切分：pi + lo(10) + t
译码：pi→屁（编码）；lo→10（编码，象形"10"）；t→伞（编码，t 形似伞）
碎片意象：屁从高空坠落；10 米高的落差；一把接住人的伞
串联成句：屁(pi)载着飞行员(pilot)从10(lo)米摔到伞(t)上。
复习：当天 / 隔天 / 每周
```
说明：词义"飞行员"中插为"载着"的宾语，完全进剧情，融合度最高。

## 2. machine = 机器（熟词法 + 编码法 + 中插最融合，创意拆解示范）

> 注：`ma/chin/e` 为创意切分，不在 `mapping.json` 中；本例用于展示"熟词+编码+中插融合"的成句质量，非取自映射库。

```
【machine】机器（n.）
切分：ma + chin + e
译码：ma→妈（拼音）；chin→下巴（熟词）；e→鹅（编码，e 似鹅）
碎片意象：妈妈；被塞进某物里的下巴；一只饿疯的鹅
串联成句：妈妈(ma)把下巴(chin)塞进机器(machine)，被饿(e)疯的鹅咬碎，血溅满脸。
复习：当天 / 隔天 / 每周
```
说明：机器是"塞进"的宾语，词义融进动作，非贴标。

## 3. earthquake = 地震（熟词法 + 恐怖）

```
【earthquake】地震（n.）
切分：earth + quake
译码：earth→地球（熟词）；quake→震动（熟词）
碎片意象：脚下地球裂开；整栋楼剧烈抖动
串联成句：恐怖废墟里，脚下的地球(earth)在疯狂震动(quake)，把你活埋在地震(earthquake)的废墟下。
复习：当天 / 隔天 / 每周
```

## 4. chase = 追赶（谐音法 + 恐怖）

```
【chase】追赶（v.）

译码：chase→锤死（谐音）
碎片意象：午夜走廊；举锤的凶手；被追的人
串联成句：午夜走廊，那个锤死(chase谐音)你的凶手正疯狂追赶你。
复习：当天 / 隔天 / 每周
```

## 5. level = 水平（找特点法）

```
【level】水平（adj./n.）
切分：l + e + v + e + l（看结构）
译码：找特点——两个 L 在同一水平线上
碎片意象：左右两个 L 像两根支柱，托住中间"水平"的横线
串联成句：level 左右两个 L 像两根柱子，死死撑住中间的横线，始终保持在一条水平(level)线上。
复习：当天 / 隔天 / 每周
```

## 劣质示例与正误对照（必须避免）

### 红线 1：词义贴标（最易犯，必须重写）
句尾用「——这就是X」「——这叫X」「X。」把英文词义当标签甩在句外，一律**禁止**，属贴标。词义必须成为画面里"活着"的角色——场景的地点、动作的对象、因果的一环。

- 误：「…血溅满脸——这就是机器(machine)。」（词义悬句外）
- 正：「妈妈(ma)把下巴(chin)塞进机器(machine)，被饿(e)疯的鹅咬碎，血溅满脸。」（机器是"塞进"的宾语，进剧情）

### 红线 2：拆分模块颠倒字母顺序
拆分模块必须按单词原字母顺序出现；若把靠后的模块放到前面，回忆时无法还原拼写。

- 误（bright = b+right，却写成）：「右边(right)不(b)敢睁眼……」（right 被放到 b 前面）
- 正：「不(b)敢看右边(right)的灯……」（b 先、right 后，锁回原序）

### 红线 3：中文句法逻辑不通
串联句必须满足**中文主谓宾语序正常、读起来通顺**；硬插「【词义】」注释、语序颠倒、成分残缺、拗口一律重写。
**中文逻辑是及格线，融合度是准线，情绪强度是排名。**

### 红线 4：无词义 / 红线 5：编造
- 无词义：只记"屁10伞"却不出现"飞行员"，回忆时丢含义。
- 编造：与发音/拼写无关的联想硬凑（如给 pilot 硬加"披萨"）。

### 红线 6：漏译字母（尽量不丢任何字母）
拆分后每个模块的译码必须覆盖该模块内的**全部字母**，任何字母不得孤立无对应。拼音/谐音会带额外元音属正常，但原词字母一个都不能少；拆得太碎导致单辅音尾（如独立成段的 p、t 无元音承载）时，须并入相邻模块或改用熟词/整体谐音。

- 误（suppose = sup+pose，sup 只译「撒(sa)」）：「他撒(sup)开姿势(pose)，假装(suppose)在走秀……」（字母 **p** 被整个漏掉，回忆时拼不出 suppose）
- 正：「苏(su)屁(pi)假装(suppose)摆出坡(po)色(se)造型，逗得全班大笑。」（sup=苏+屁 覆盖 s-u-p；pose=坡+色 覆盖 p-o-s-e，七个字母全在，顺序未乱）

### 七组正/误对照（实跑复盘，来自第二批 10 词）

**birthmark = 胎记**（违红线 1：贴标）
- 误：「刚出生(birth)的婴儿皮肤上，多了块标记(mark)——这就是胎记(birthmark)。」
- 正：「刚出生(birth)的婴儿，皮肤上的标记(mark)被全家当胎记(birthmark)摸了又摸。」（胎记成"摸"的宾语）

**strawberry = 草莓**（违红线 1：贴标）
- 误：「稻草(straw)堆里长出一串红浆果(berry)——这就是草莓(strawberry)。」
- 正：「孩子扒开稻草(straw)找红浆果(berry)，塞进嘴才发现是草莓(strawberry)的味儿。」（草莓成"发现"的味觉对象）

**crowded = 拥挤的**（违红线 1：贴标）
- 误：「人群(crowd)里饿(e)得(d)发慌的人挤成一团——这就是拥挤(crowded)。」
- 正：「饿(e)得(d)发慌的人群(crowd)挤爆车门，车厢拥挤(crowded)得脚都悬空。」（拥挤作车厢状态谓语）

**cover = 覆盖**（违红线 1：贴标）
- 误：「把可乐(co)倒满，维(ver)生素片盖上去——这就是覆盖(cover)。」
- 正：「把可乐(co)倒满，维(ver)生素片盖上去，刚好覆盖(cover)住整个杯口。」（覆盖成收尾动作）

**although = 虽然**（违红线 1：贴标，连词作因果一环）
- 误：「艾尔(al)虽(al)然绕(though)了远路，也赶到了——这就是虽然(although)。」
- 正：「艾尔(al)明知绕(though)远，虽然(although)腿软还是冲到了终点。」（虽是转折逻辑链的一环）

**bright = 明亮的**（违红线 2：字母顺序）
- 误：「右边(right)不(b)敢睁眼，灯太明亮(bright)刺得直流泪。」（right 先于 b）
- 正：「不(b)敢看右边(right)的灯，明亮(bright)刺得直流泪。」（b 先于 right）

**suppose = 假设/假装**（违红线 6：漏译字母）
- 误：「他撒(sup)开姿势(pose)，假装(suppose)在走秀，逗得全场大笑。」（sup 只译"撒(sa)"，字母 **p** 被漏掉）
- 正：「苏(su)屁(pi)假装(suppose)摆出坡(po)色(se)造型，逗得全班大笑。」（sup=苏+屁 覆盖 s-u-p；pose=坡+色 覆盖 p-o-s-e，七字母全在）
