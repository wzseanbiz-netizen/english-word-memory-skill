> 本文件是 `SKILL.md` 的展开与依据。包含：方法来源、六类记忆法、从实例归纳的规律、七步框架细则、成句规则与原则、适用建议、以及「事实 / 推测」边界。

## 一、方法来源（可验证事实）

本方法的根基来自两份可查资料：

1. **《英语单词记忆》PPT（26 页）**：第 2 页给出方法总览，核心为**六类记忆法**，每类都有固定示例：
   - **归纳法**（4–6 页）：把拼写相近、共享词根的词归组。例：angle 词族（angle、bangle、dangle、tangle、entangle、untangle…），用首字母拼音（b=臂、d=吊、t=探戈）+ 前后缀（en- 使…、un- 反义）串记。
   - **熟词法**（8–11 页）：把生词拆成熟英文词/词块。例：hesitate=he+sit+ate（他坐着吃→犹豫）；catcall=cat+call（猫叫→喝倒彩）；widow=window−n（寡妇擦窗泥）。
   - **拼音法**（12–15 页）：在词里找拼音对应汉字。例：change=嫦(chang)娥(e)；danger=挡(dang)儿(er)；advantage=阿弟(ad)玩(van)他哥(ta ge)。
   - **编码法**（16–20 页）：给字母编形象（象形/谐音/拼音首字母/单词首字母/特定含义）。例：pilot=屁(pi)10(lo)伞(t)；dirty=敌(di)人(r)汤圆(ty)；boom=600(boo)麦当劳(m)。
   - **谐音法**（21–23 页）：整体/部分谐音成中文。例：chase=锤死；bamboo=半步。
   - **找特点**（24–25 页）：抓视觉/结构特征。例：level 两个 L 在同一水平线→"水平"。

2. **两份词汇文档**：小学外研版三年级上册、初中七至九年级（约 320 词）。格式完全一致：每个单词配一条"联想"记忆句。小学片段短（1–2 个），初中文档更长、附英文例句、按单元分组。

3. **词根词缀法（第二种记忆法，用户于本 skill 中确立）**：原两份 PPT 仅在"初中适用建议"提及"熟词法 + 词根词缀"，未给出独立方法或词素表。本 skill 将其**确立为与联想法并列的第二种记忆法**，词素表（前缀/后缀/词根）来自通用英语形态学常识，收录于 `references/affix.md`，可随教学增删。

> 第 1、2 点为可验证事实，来源于被分析的原始资料；第 3 点为本次方法设计新增，已显式标注来源。

## 二、从实例归纳的规律（个人分析）

对两份词汇文档"单词—联想句"格式的共性归纳（文档本身未直接写明，属基于实例的分析）：

- **规律一·先拆后译**：所有词先拆成 2–4 片段，再逐段映射中文。小学片段短，初中片段长且多词根。
- **规律二·音义双通道**：每段用"拼音首字母/谐音"对上发音，再用一句荒诞、画面强的短句把片段与词义绑在一起。荒诞性强化记忆点（"联想句"形式的个人解释）。
- **规律三·熟词法是长词主力**（初中明显）：大量"拆成熟词/已知词块 + 拼音补余"。
- **规律四·分组编排 + 例句支撑**：按教材单元分组，初中附英文例句；分组即语境化、间隔化学习。
- **规律五·结构稳定、可批量复制**："单词—词义—联想句"三段式，使方法可标准化套用，适合沉淀为可重复流程。

## 三、七步记忆框架（个人设计的可操作方案）

以下 7 步为基于上述事实与规律设计的落地流程。第 5 步「串联成句」是提取线索最强的一环。

| 步骤 | 名称 | 操作要点 |
|------|------|----------|
| 0 | 定词 | 选目标词，查明词义、词性，准备例句（缺省则补全并标注）。 |
| 1 | 切分 | 段数由词决定、按意象灵活定：能整词就整词（单段合法），能 2 段不 3 段；**少能拆就少拆，拆不出时可多拆，上限 6 段**——4 段与 5 段**择优**（4 段能顺出同样清楚的画面就用 4 段，5 段更顺就用 5 段，5 段不算错）；某段实在查不到出处、也拼不成拼音时，允许拆到 6 段（university→u+ni+v+er+si+ty）；优先在熟词处断（earthquake→earth+quake），**不逐字母切**；不论几段，串联句都要简洁明了。总判据：这套拆法背起来要比直接背单词省力。 |
| 2 | 译码 | **四法优先级固定：熟词 > 拼音 > 编码 > 谐音**；前三法有干净解绝不用谐音。同词不同段可换法，同段并排试多法再比选。**谐音三关缺一不可**：①读音真接近；②意象真实存在；③画面与词义有因果连接——过不了就换切分换法，宁可不改别硬凑。编码法仅当其他法无好解时用，绝不逐字母拆。 |
| 3 | 碎片意象 | 每段造一个荒诞、有画面的"小镜头"，只备料、不成句。 |
| 4 | 串联成句★ | 把碎片意象 + 英文词义焊成【一句】短句，须满足结构规则与成句原则。 |
| 5 | 固化 | 当天/隔天/每周三次复习；先回忆串联句，再回想词义。 |
| 6 | 归纳 | 同族词用归纳法归并；特殊词用找特点法。 |

## 四、成句结构规则（硬约束，共六条，与 SKILL.md 一致）

写串联句除情绪强度外，还必须满足六条结构约束——否则句子虽好记却还原不出拼写，或词义悬在句外。这六条是"门槛"：不过则废；过后再用"成句原则"的情绪强度/融合度/通顺度做"排名"选最优。

1. **模块顺序锁定**：拆分模块必须按单词原字母顺序出现，不得打乱、跳序。
   - 正例：pilot → pi + 10(lo) + t（对应 p-i-l-o-t 先后）。
   - 反例：写成 t + pi + 10——顺序打乱，回忆时无法还原拼写。
   - 多字母模块（如 lo 表 10）也按它在词里的先后位置摆。

2. **词义融合（高于位置）**：中文意思必须成为画面里"活着"的角色——地点、对象、因果一环——而非句尾"这就是 X"的标签。三向嵌入只解决"放哪"，本条解决"融没融进去"。句尾甩标签一律重写，包括「——这就是X」和换皮的「这是X / 那是X / 就是X / 全是X」（去掉破折号但词义仍悬句尾，不算改好）。
   - 融合佳（机器）："妈妈(ma)把下巴(chin)塞进机器(machine)，被饿(e)疯的鹅咬碎，血溅满脸。"——机器是动作对象，完全进剧情。
   - 融合差（贴标）："…血溅满脸——这就是机器(machine)。"——词义悬在句外，回想时最易丢。

3. **词义三向嵌入（放哪的参考，须在融合前提下）**：

| 位置 | 写法（须融进剧情，非贴标签） |
|------|------------------------------|
| 前置(背景) | "飞行员(pilot)驾着屁(pi)从10(lo)米摔到伞(t)上。" |
| 中插(动作一环) | "屁(pi)载着飞行员(pilot)从10(lo)米摔到伞(t)上。"（词义成动词合理成分，最融合） |
| 后置(收尾,偏弱) | "屁(pi)从10(lo)米摔到伞(t)上——这就是飞行员。"（仅无融合点时才用） |

中插不再一律淘汰：只有当词意被硬插成"【飞行员】"注释、破坏句法时才淘汰；若它成了动词合理成分（"塞进机器""载着飞行员"），中插最融合。

4. **中文句法逻辑通顺（及格线）**：主谓宾语序正常、读来通顺；硬插"【词义】"注释、语序颠倒、成分残缺或拗口一律筛掉重写。中文逻辑是门槛，融合度是准线，情绪强度是排名。

5. **字母全覆盖（不可漏译，含机械核对动作）**：拆分后每个模块的译码必须覆盖该模块内的全部字母，任何字母不得孤立无对应（如 sup 不能只译"撒(sa)"漏掉 p）。孤立单辅音尾须并入相邻模块或改用熟词/整体谐音处理。**切分定稿前必做"拼接核对"**（机械动作，不靠自觉）：把各段英文字母按顺序拼回去，逐字符等于原词才算过——bu+tt+er+fly→"butterfly" ✓；bu+te+r→只有"butter"，漏 t 又丢 fly，当场现形。双写字母（ss/tt/ll/ee…）逐个点名去处，或合并成一个双字母段（两把伞/两只海马）。

6. **单句因果链（最高优先级·一票否决）**：一条串联句只能是一条因果链，禁止几个画面并列——没有逻辑关系的句子不好记。自检三问：①从第二个画面起能否接「因为…所以 / 为了…就」？只能加逗号并列＝不合格；②词义是句中人物正在做的动作/目的，还是句尾补结论？后者不合格；③删掉末半句，画面仍能辨出词义吗？
   - 并列差例："火星(mar)上有个人(tian)在挖矿，还有一个厕所。"——两个画面硬摆一起，回想时丢一半。
   - 因果佳例："火星(mar)人(tian)为了填矿坑拼命挖矿。"——挖矿（词义）是火星人为了目标手上正干的活儿，删掉后半句画面残缺。
   - 改法：把词义变成画面人物手上的活儿；禁用「是个XX / 成了XX / 被…得XX / ——这就是XX / 这是XX / 那是XX / 就是XX」式解说收尾（末小句是短判断句、把词义当标签甩出的一律重写）；形容词稳写法：词义进状语 + 动作收尾。

> **译码正确性铁律（不占结构规则名额，但同样不可破）**：标"熟词"的片段，中文必须是该英文片段在字典里的真实常用义，不得把别的词或中文固有词的意思硬塞给它——`an` 是"一个"不是"在"（在是 in），`ex` 不是"儿媳"，`tie` 是"领带/系"不是"铁"，`dent` 是"凹痕"不是"牙"。对不上就改标"编码"（编码是显式记忆码，不宣称字典义），不许硬凑错义。**拼音段同理**：汉字读音必须与该段字母严格对应——ca→擦(cā)对，写成"卡(kǎ)"就是错，不许抓音近字充数；拼音首字母合法（pp→婆婆），但每个字母须逐字对应（蜘蛛 zhī-zhū 是 zh 声母，不能进 zz）。**拼音凭读音认账**：标"拼音"的唯一条件是**这个字母串真的拼得出这个汉字**——`ha`=哈（hā）对，字母就是 hā 的拼写；`mu`=牛 错，牛是 niu，字母变了，mu 读出来是"木"的音。**音近码没有退路**："读音像但拼不成音节就改标编码"这条旧办法已作废（编码现在必须有出处，查不到也报错），`票≈peo`、`搜≈so`、`兔≈to`、`铺了≈ple`、`固≈goo`、`惹≈ry` 一律换切分重做，不许靠改标签蒙过去。**双写字母段选型**：段位要"动"用拼音首字母人物词（pp→婆婆，表见 mapping.json `pinyin` 段），当道具用编码复数（ss→两条海马、tt→两把伞），画面质量相当时优先编码复数（与单字母表一致、零新增）。另：每段意象须真实存在、能立刻想出画面，生造组合一律换拆法。**谐音少用、编码不乱编**：谐音是最后兜底，能熟词/拼音/首字母/象形解决就别用；编码虽不宣称字典义，但须与片段的形或音有合理联系（bu≈布、re≈热、co=可乐），不能毫无依据乱配一个意象，音近码如实标编码别冒充拼音/熟词。宁可换拆法、宁可不改，别硬凑。**编码必须有出处**：标"编码"的段，字母串必须能在编码库里查到（课件字母表 / 组合表 / 编码表 / 生活常识缩写表 / 拼音表），查不到就是不认账的自造硬编码——`wi`=喂（拼音只有 wei，i 也不作首字母）、`pe`=陪（pei 不是 pe）、`lo`=漏、`pho`=破碗 一律不许，改换有出处的段或换切分。**生活常识缩写也是出处**（用户 2026-11-26 定：「日常生活用到的好理解的包括 IC=IC卡，CT=医院的CT检查，ID=身份证 都可以通过」）：`ic`=IC卡、`ct`=CT检查、`id`=身份证、`tv`/`cd`/`dvd`/`dna`/`usb`/`app`/`atm`/`gps`/`vip` 直接当编码用，零认知负担；写全称也算对齐（`ct` 写"CT检查""医院的CT检查"都过），这类缩写允许出现在意象里（A10 白名单），白名单外的英文照拦。**而且意象要对齐库值**：一个码只有一个意象——库里 `fi`=鱼，写「肥」「飞镖」就不算这个码（用户 2026-11-26 定）；**此限只约束标「编码」的段**：同一字母串另有合法身份时互不冲突——`ad` 作熟词是「广告」（真实缩写，isRealWord 认账），作编码或拼音首字母是「阿弟」；`th` 写「桃花」（táo huā）或「图画」（tú huà）都过首字母逐字对应，`图画` 本身又是组合表编码值——标哪个就按哪条校验，只看画面顺不顺，不许为了统一把合法的熟词段硬换成编码、也不许把整库 `th` 一律写桃花（用户 2026-11-26 定）。**拼音首字母段不用入库**：只要字母数＝汉字数、逐字首字母对得上（≤3 字母），就是合法段，不必写进 `py-tables.json`——`ct`=餐厅/抽屉、`pe`=胖鹅、`et`=儿童、`ed`=耳朵、`ff`=肥肥、`ck`=仓库、`ght`=桂花糖 都直接标首字母，同一段在不同词里换意象也不报（用户 2026-11-26 定「拼音首字母不用落编码，只要能把句子连顺好记」）；`ch`=菜花 写成「窗户」应改标「拼音首字母」，`re`=热 写成「反复」是另配意象，都要改回来。**历史登记不再豁免**：查不到出处就拦，不许以"以前这么写过"为由保留。**数字象形码也是出处**：整段全由 `l`=1 / `z`=2 / `s`=5 / `b`=6 / `o`=0 组成时按数字读——`lo`=10、`llo`=110、`loo`=100、`zo`=20、`zoo`=200、`so`=50、`boo`=600；读法唯一，`llo` 只能读 110。**补充固定码也是出处**：`fi`=鱼（取 fish 开头两字母，2026-11-26 定）已在规则表定案，`fi` 写成"肥/飞镖"要对齐成"鱼"。**拟声一律不用**：不设"拟声"这一路——拟声等于让人额外背一层"这个声音该这么拼"，白加记忆负担（用户 2026-11-26 定）。`mu`=牛叫、`moo`=哞、`sh`=嘘、`val`=哇一声、`cle`=笔尖点纸、`cam`=快门咔 全部作废；同一个声音改用拼音（ha=哈 hā）、拼音首字母、编码或象形交代。**片段义项要合语法**：疑问词/副词（哪里、什么、怎么、如何、为什么）不能当名词受量词修饰——"每一个哪里"想不出画面（where 是疑问副词），要放回它的疑问用法里（"问一句：哪里见过这孩子"）。**句子要短、要主谓宾、不要修辞**（用户 2026-11-26 定）：一句话说完谁做了什么，8–25 字最好，过 30 字先想哪半句能删；**比喻一律不要**——「像…」「如同…」「…似的」「和…一样」「仿佛」「宛如」「犹如」只加一层"像什么"的转述，读者容易照着喻体想偏，抓不住字面画面。判法：删掉喻体动作还在不在？在就直接写那个动作（脚蹬子**像**笔一样画圈 → 他拿脚一蹬，轮子转着把车带走）。名词「雕像/画像/神像」不是比喻，照常用。

> **学段适配（熟词分级，与 SKILL.md 一致）**：熟词以学习者学段为准，不以字典常用度为准——用生词当记忆挂钩，等于用生词记生词。小学用户只有课本级词汇（apple/cat/run/big 级）可标熟词；超出学段的片段改用象形编码 + 拼音首字母（不依赖任何英语词汇量），片段 1–2 段为宜，句子生活化。

## 五、成句原则：通感 · 情绪唤醒

**一句话定律：串联句越有趣、越通感（刺激/恐怖），越好记。**

原理（记忆科学支撑）：情绪唤醒（尤其恐惧、惊奇）由杏仁核激活，强化海马体记忆巩固；"通感"把声音、画面、触觉、痛感写进同一句，等于多打几条提取线索，回忆时任意一条都能拽出整词。

写串联句按以下强度档位往上叠（越靠后越牢）：

| 档位 | 手法 | 例子（绑词义） |
|------|------|----------------|
| ① 荒诞 | 不合常理的画面 | "地球长出了耳朵" |
| ② 通感 | 声音+画面+触觉叠写 | "锤子砸下的闷响震得手心发麻" |
| ③ 刺激 | 强烈感官/痛感 | "指甲刮过黑板，牙根发酸" |
| ④ 恐怖 ★ | 死亡/被追/活埋等威胁感 | "凶手锤死你前，你听见自己骨头碎裂" |

实操要点：
- 先保荒诞①，再叠通感②、刺激③，能上恐怖④最好——威胁感是记忆"免费加速器"。
- 句子必须出现英文词义本身（如"地震""追赶"），让画面直接锚定含义，而非只记谐音。
- 只编 1 句，太长稀释情绪；越短越狠越难忘。
- **四法混用，末位选最优组合（核心决策）**：译码阶段四法（熟词/拼音/编码/谐音）不互斥——同一单词的不同段可用不同法，同一段也可并排试多种法。成句时先据此组合出 2–3 版候选句（A 版全用编码、B 版混用谐音+熟词…），再按"成句结构规则"六条筛掉不过关的（门槛），从通过的里挑最有趣/最通感/最通顺那句（排名）。中文逻辑是门槛，融合度是准线，情绪强度是排名。

## 六、适用建议

本 skill 含**两种相互独立的记忆法**：方法一「联想记忆法」（七步框架，熟词/拼音/编码/谐音/找特点）与方法二「词根词缀记忆法」（形态拆解）。对同一词**并列给出两版方案、方案内不混写**，供对比择优。

| 学段 / 词型 | 更适用（同一词并列两版） | 操作要点 |
|-------------|----------|----------|
| 小学（词短、具象） | 方法一·联想记忆法（拼音首字母 + 象形） | 片段 1–2 个；句子具体、贴近生活。 |
| 初中（词长、抽象·派生明显） | **方法二·词根词缀记忆法**（独立成句） | 拆前后缀+词根；附英文例句；不掺联想法画面。 |
| 难点词/抽象词（不透明） | 方法一·联想记忆法（音近中文/熟词优先） | 音近中文直接挂钩，降低门槛。 |
| 同族词 | 方法二·词根词缀记忆法优先 | 按词根/前后缀成组记忆，效率最高（如 -ject 家族）。 |
| 全程 | 两版并列 + 严格间隔重复 | 避免一次性死记；每组学完做归纳。 |

**方法选择（同一词并列两版，方案内不混写）**：对每个单词同时给出方法一（联想记忆法）与方法二（词根词缀记忆法）两版独立方案，并列在同一单词下供对比择优。**不混写**指同一版记忆句内不把联想画面与词素推导拼在一起；方法一内部的四法（熟词/拼音/编码/谐音）混用只发生在方法一内部，与方法二无关。某法对该词不适用（如 moon 无可拆词素）时，该栏标注「不适用」并保留另一版。

**个人分析与设计：**

- 第三部分的"七步框架"为基于上述事实设计的可操作方案，文档未直接给出该框架。
