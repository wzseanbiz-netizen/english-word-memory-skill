# 英语单词记忆逻辑框架（详细版）

> 本文件是 `SKILL.md` 的展开与依据。包含：方法来源、六类记忆法、从实例归纳的规律、七步框架细则、成句规则与原则、适用建议、以及「事实 / 推测」边界。
> 使用者（智能体）只需在 `SKILL.md` 的指导下执行；本文件用于理解"为什么这样设计"和查阅细节。

## 一、方法来源（可验证事实）

本方法的根基来自两份可查资料：

1. **《英语单词记忆》PPT（26 页）**：第 2 页给出方法总览，核心为**六类记忆法**，每类都有固定示例：
   - **归纳法**（4–6 页）：把拼写相近、共享词根的词归组。例：angle 词族（angle、bangle、dangle、tangle、entangle、untangle…），用首字母拼音（b=臂、d=吊、t=探戈）+ 前后缀（en- 使…、un- 反义）串记。
   - **熟词法**（8–11 页）：把生词拆成熟英文词/词块。例：hesitate=he+sit+ate（他坐着吃→犹豫）；catcall=cat+call（猫叫→喝倒彩）；widow=window−n（寡妇擦窗泥）。
   - **拼音法**（12–15 页）：在词里找拼音对应汉字。例：change=嫦(chang)娥(e)；danger=挡(dang)儿(er)；advantage=阿弟(ad)玩(van)他哥(ta ge)。
   - **编码法**（16–20 页）：给字母编形象（象形/谐音/拼音首字母/单词首字母/特定含义）。例：pilot=屁(pi)10(lo)伞(t)；dirty=敌(di)人(r)汤圆(ty)；boom=600(boo)麦当劳(m)。
   - **谐音法**（21–23 页）：整体/部分谐音成中文。例：chase=锤死；bamboo=半步。
   - **找特点**（24–25 页）：抓视觉/结构特征。例：level 两个 L 在同一水平线→"水平"。

2. **两份词汇文档**：小学外研版三年级上册、初中七至九年级（约 320 词）。格式完全一致：每个单词配一条"联想"记忆句。小学片段短（1–2 个），初中文档更长、附英文例句、按单元分组。

3. **词根词缀法（第二种记忆法，用户于本 skill 中确立）**：原两份 PPT 仅在"初中适用建议"提及"熟词法 + 词根词缀"，未给出独立方法或词素表。本 skill 将其**确立为与联想法并列的第二种记忆法**，词素表（前缀/后缀/词根）来自通用英语形态学常识，收录于 `references/affix.md`，可随教学增删。

> 第 1、2 点为可验证事实，来源于被分析的原始资料；第 3 点为本次方法设计新增，已显式标注来源。

## 二、从实例归纳的规律（个人分析）

对两份词汇文档"单词—联想句"格式的共性归纳（文档本身未直接写明，属基于实例的分析）：

- **规律一·先拆后译**：所有词先拆成 2–4 片段，再逐段映射中文。小学片段短，初中片段长且多词根。
- **规律二·音义双通道**：每段用"拼音首字母/谐音"对上发音，再用一句荒诞、画面强的短句把片段与词义绑在一起。荒诞性强化记忆点（"联想句"形式的个人解释）。
- **规律三·熟词法是长词主力**（初中明显）：大量"拆成熟词/已知词块 + 拼音补余"。
- **规律四·分组编排 + 例句支撑**：按教材单元分组，初中附英文例句；分组即语境化、间隔化学习。
- **规律五·结构稳定、可批量复制**："单词—词义—联想句"三段式，使方法可标准化套用，适合沉淀为可重复流程。

## 三、七步记忆框架（个人设计的可操作方案）

以下 7 步为基于上述事实与规律设计的落地流程。第 5 步「串联成句」是提取线索最强的一环。

| 步骤 | 名称 | 操作要点 |
|------|------|----------|
| 0 | 定词 | 选目标词，查明词义、词性，准备例句（缺省则补全并标注）。 |
| 1 | 切分 | 按熟词/表音块拆，段数越少越好（通常 2–3 段、最多 4 段）；优先在熟词处断（earthquake→earth+quake），**不逐字母切**。 |
| 2 | 译码 | 四法选最优组合（熟词/拼音/编码/谐音不互斥，同词不同段可换法，同段并排试多法）；**目标=模块尽量少、每段好记**——首选熟词/拼音把大块并成好记中文，编码法仅当其他法无好解时用，绝不逐字母拆。 |
| 3 | 碎片意象 | 每段造一个荒诞、有画面的"小镜头"，只备料、不成句。 |
| 4 | 串联成句★ | 把碎片意象 + 英文词义焊成【一句】短句，须满足结构规则与成句原则。 |
| 5 | 固化 | 当天/隔天/每周三次复习；先回忆串联句，再回想词义。 |
| 6 | 归纳 | 同族词用归纳法归并；特殊词用找特点法。 |

## 四、成句结构规则（硬约束，共五条，与 SKILL.md 一致）

写串联句除情绪强度外，还必须满足五条结构约束——否则句子虽好记却还原不出拼写，或词义悬在句外。这五条是"门槛"：不过则废；过后再用"成句原则"的情绪强度/融合度/通顺度做"排名"选最优。

1. **模块顺序锁定**：拆分模块必须按单词原字母顺序出现，不得打乱、跳序。
   - 正例：pilot → pi + 10(lo) + t（对应 p-i-l-o-t 先后）。
   - 反例：写成 t + pi + 10——顺序打乱，回忆时无法还原拼写。
   - 多字母模块（如 lo 表 10）也按它在词里的先后位置摆。

2. **词义融合（高于位置）**：中文意思必须成为画面里"活着"的角色——地点、对象、因果一环——而非句尾"这就是 X"的标签。三向嵌入只解决"放哪"，本条解决"融没融进去"。
   - 融合佳（机器）："妈妈(ma)把下巴(chin)塞进机器(machine)，被饿(e)疯的鹅咬碎，血溅满脸。"——机器是动作对象，完全进剧情。
   - 融合差（贴标）："…血溅满脸——这就是机器(machine)。"——词义悬在句外，回想时最易丢。

3. **词义三向嵌入（放哪的参考，须在融合前提下）**：

| 位置 | 写法（须融进剧情，非贴标签） |
|------|------------------------------|
| 前置(背景) | "飞行员(pilot)驾着屁(pi)从10(lo)米摔到伞(t)上。" |
| 中插(动作一环) | "屁(pi)载着飞行员(pilot)从10(lo)米摔到伞(t)上。"（词义成动词合理成分，最融合） |
| 后置(收尾,偏弱) | "屁(pi)从10(lo)米摔到伞(t)上——这就是飞行员。"（仅无融合点时才用） |

中插不再一律淘汰：只有当词意被硬插成"【飞行员】"注释、破坏句法时才淘汰；若它成了动词合理成分（"塞进机器""载着飞行员"），中插最融合。

4. **中文句法逻辑通顺（及格线）**：主谓宾语序正常、读来通顺；硬插"【词义】"注释、语序颠倒、成分残缺或拗口一律筛掉重写。中文逻辑是门槛，融合度是准线，情绪强度是排名。

5. **字母全覆盖（不可漏译）**：拆分后每个模块的译码必须覆盖该模块内的全部字母，任何字母不得孤立无对应（如 sup 不能只译"撒(sa)"漏掉 p）。孤立单辅音尾须并入相邻模块或改用熟词/整体谐音处理。

> **译码正确性铁律（不占结构规则名额，但同样不可破）**：标"熟词"的片段，中文必须是该英文片段在字典里的真实常用义，不得把别的词或中文固有词的意思硬塞给它——`an` 是"一个"不是"在"（在是 in），`ex` 不是"儿媳"，`tie` 是"领带/系"不是"铁"，`dent` 是"凹痕"不是"牙"。对不上就改标"编码"（编码是显式记忆码，不宣称字典义），不许硬凑错义。另：每段意象须真实存在、能立刻想出画面，生造组合一律换拆法。

## 五、成句原则：通感 · 情绪唤醒

**一句话定律：串联句越有趣、越通感（刺激/恐怖），越好记。**

原理（记忆科学支撑）：情绪唤醒（尤其恐惧、惊奇）由杏仁核激活，强化海马体记忆巩固；"通感"把声音、画面、触觉、痛感写进同一句，等于多打几条提取线索，回忆时任意一条都能拽出整词。

写串联句按以下强度档位往上叠（越靠后越牢）：

| 档位 | 手法 | 例子（绑词义） |
|------|------|----------------|
| ① 荒诞 | 不合常理的画面 | "地球长出了耳朵" |
| ② 通感 | 声音+画面+触觉叠写 | "锤子砸下的闷响震得手心发麻" |
| ③ 刺激 | 强烈感官/痛感 | "指甲刮过黑板，牙根发酸" |
| ④ 恐怖 ★ | 死亡/被追/活埋等威胁感 | "凶手锤死你前，你听见自己骨头碎裂" |

实操要点：
- 先保荒诞①，再叠通感②、刺激③，能上恐怖④最好——威胁感是记忆"免费加速器"。
- 句子必须出现英文词义本身（如"地震""追赶"），让画面直接锚定含义，而非只记谐音。
- 只编 1 句，太长稀释情绪；越短越狠越难忘。
- **四法混用，末位选最优组合（核心决策）**：译码阶段四法（熟词/拼音/编码/谐音）不互斥——同一单词的不同段可用不同法，同一段也可并排试多种法。成句时先据此组合出 2–3 版候选句（A 版全用编码、B 版混用谐音+熟词…），再按"成句结构规则"五条筛掉不过关的（门槛），从通过的里挑最有趣/最通感/最通顺那句（排名）。中文逻辑是门槛，融合度是准线，情绪强度是排名。

## 六、适用建议

本 skill 含**两种相互独立的记忆法**：方法一「联想记忆法」（七步框架，熟词/拼音/编码/谐音/找特点）与方法二「词根词缀记忆法」（形态拆解）。对同一词**并列给出两版方案、方案内不混写**，供对比择优。

| 学段 / 词型 | 更适用（同一词并列两版） | 操作要点 |
|-------------|----------|----------|
| 小学（词短、具象） | 方法一·联想记忆法（拼音首字母 + 象形） | 片段 1–2 个；句子具体、贴近生活。 |
| 初中（词长、抽象·派生明显） | **方法二·词根词缀记忆法**（独立成句） | 拆前后缀+词根；附英文例句；不掺联想法画面。 |
| 难点词/抽象词（不透明） | 方法一·联想记忆法（音近中文/熟词优先） | 音近中文直接挂钩，降低门槛。 |
| 同族词 | 方法二·词根词缀记忆法优先 | 按词根/前后缀成组记忆，效率最高（如 -ject 家族）。 |
| 全程 | 两版并列 + 严格间隔重复 | 避免一次性死记；每组学完做归纳。 |

**方法选择（同一词并列两版，方案内不混写）**：对每个单词同时给出方法一（联想记忆法）与方法二（词根词缀记忆法）两版独立方案，并列在同一单词下供对比择优。**不混写**指同一版记忆句内不把联想画面与词素推导拼在一起；方法一内部的四法（熟词/拼音/编码/谐音）混用只发生在方法一内部，与方法二无关。某法对该词不适用（如 moon 无可拆词素）时，该栏标注「不适用」并保留另一版。
